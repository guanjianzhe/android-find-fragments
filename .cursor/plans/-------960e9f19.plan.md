## 核心修改

### 1. 修改 `display_results()` 函数

简化输出格式，移除序号 `[0]`, `[1]`，改用简洁符号：

```python
def display_results(activity_name: str, activity_path: Optional[str], 
                   fragments: List[Tuple[str, Optional[str]]]) -> List[Tuple[int, str, Optional[str]]]:
    indexed = []
    
    # 显示 Activity
    print(f"Activity: {activity_name}")
    if activity_path:
        print(f"  {activity_path}")
    else:
        print("  [未找到]")
    indexed.append((0, activity_name, activity_path))
    
    # 显示 Fragments
    if fragments:
        print(f"\nFragments ({len(fragments)})")
        for idx, (name, path) in enumerate(fragments, start=1):
            print(f"  • {name}")
            if path:
                print(f"    {path}")
            indexed.append((idx, name, path))
    else:
        print("\n无 Fragment")
    
    return indexed
```

### 2. 修改 `watch_mode()` 输出格式

### 3. 添加颜色支持（可选）

使用 ANSI 颜色码增强可读性：

- `→` 和时间：青色
- Activity 名称：加粗
- Fragment 符号 `•`：普通
- 找到的路径：绿色
- 未找到提示：黄色/灰色
```python
# ANSI 颜色码常量

RESET = '\033[0m'
```
